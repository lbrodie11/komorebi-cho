# Komorebi-chō

*A tiny Tokyo backstreet that lives in your browser. Build a little. Watch it notice.*

Komorebi-chō (木漏れ日町, "sunlight-through-the-leaves town") is a free, cozy, web-first living diorama: a fictional Yanaka-style shitamachi block on a walnut plinth. A 3D scene is rendered at low resolution through a palette-and-dither pass, so every frame reads as pixel art. Fourteen neighbours keep their own routines. Place something new and the ones nearby come over to look, remember it, and start using it.

Everything is generated by code: the buildings, textures, signage, the 47-colour palette, the lo-fi piano score and the cicadas. There are no image, model or audio files.

**Play:** <https://lbrodie11.github.io/komorebi-cho/>. Every push to `main` deploys there.

## Run it locally

Needs Node 24 (`nvm use` reads `.nvmrc`).

```bash
npm ci
npm run dev
```

Open the printed URL and press **Sound on**. Before committing, run all four gates (CI runs the same ones):

```bash
npm run lint && npm run typecheck && npm test && npm run build
```

## Controls

| Input | Action |
|---|---|
| Drag / WASD | Pan |
| Scroll / Z, C | Zoom in whole steps: 1×, 2×, 3× |
| Q / E | Rotate 90° |
| Space | Pause time |
| 1–4 | Jump to dawn / noon / dusk / night |
| B | Build mode (R rotates the item) |
| X | Remove things you placed |
| P | Photo mode |
| M | Sound on/off |
| Click a person | Meet them |

Settings offers four looks:
- **Smooth** (the default) has finer pixels and full-colour shading, for a clean voxel-diorama look.
- **Fine**, **Classic** and **Chunky** are palette pixel art at three pixel sizes.

Settings also has **Film Diffusion** (0–20%, default 5%: a soft lens glow around lights, while edges stay crisp) and a reduced-motion switch.

## URL parameters

| Parameter | Effect |
|---|---|
| `?debug` | Stats overlay: fps, frame and sim time, draw calls, triangles, textures, residents on screen |
| `?seed=N&hour=H&season=S&weather=clear\|rain&freeze=1` | A reproducible frame for screenshots and visual diffs. Never reads or writes your save. |
| `?lutOff` | Snap to the palette with the reference loop instead of the lookup table (for comparison) |
| `?diffusion=P` | Film Diffusion for this visit, in percent (0–20). Not saved. |
| `?pixel=classic` | The look for this visit: `smooth`, `fine`, `classic` or `chunky`. Not saved. |

Example: `/?seed=1&hour=19.25&season=autumn&weather=rain&freeze=1`

## What's inside

- **The block.** At the top, a sento with its tall chimney, a narrow concrete micro-home, a two-storey apāto with a steel stair, and a temple on a raised terrace. Below that, a shotengai with four shops under an entrance arch, a kissaten on a chamfered corner, a community allotment, and a pocket park with a koi pond, waterfall, vermilion bridge and a Benzaiten islet.
- **Film Diffusion.** An optional lens-diffusion pass (0–20%) glows around real light sources and turns dither into tone. At 0% the diorama is the pure palette.
- **The pixel pass.** The low-res half-float render goes through a sky, a half-res lantern glow, cloud shadows, a tonemap, hue-shifted shading, pond reflections, outlines and a Bayer dither. It then snaps to the palette through a 3D lookup table, at an exact integer upscale. Camera steps are instant, with a 250 ms dither dissolve between views, so nothing ever crawls across the pixel grid.
- **Art direction.** Weathering follows its causes: grime at wall bases and under eaves, streaks below sills and AC units, moss on north faces, darkening in rain. Hand-drawn 5×5 kana and 7×7 pictograms paint every sign. Foliage sways with the wind, and leaves fall from the trees that drop them. The plinth has a utility cutaway with labelled pipes.
- **Time and weather.** One real second is one in-world minute. The light is hand-keyed through golden hour, blue hour, rainy evenings and snowy mornings. Shops raise their shutters on schedule; at night their windows spill warm light onto the street, streetlamps pool on the ground, and homes light up one by one (some stay dark). Rain arrives gradually and the streets stay wet after it stops. Four seasons bring petals, autumn colour, snow and fireflies.
- **Residents.** Each one runs a schedule, then needs, then a utility choice over smart objects, then a reservation, then a path on a nav grid, then an action. New objects attract at most two inspectors at a time. Removing something a neighbour is using makes them stand up, look puzzled and re-plan; nobody ever teleports in view.
- **Animals.** Cats (they find cat bowls), pigeons that scatter, koi, crows circling the chimney, butterflies.
- **Audio.** Generative lo-fi piano with voice-led jazz voicings, a key that drifts with the time of day, and tape wow and vinyl crackle. Under it, a synthesised soundscape: rain, wind, the waterfall, bush warblers in spring, cicadas in summer, higurashi at dusk, and the temple bell at 6:00 and 18:00.
- **Saves.** Versioned localStorage with migrations. The game still runs if storage is unavailable.

## Stack

TypeScript (strict), Vite, three.js `WebGLRenderer` (r187), Web Audio, Vitest. The only runtime dependency is three.js. The simulation is DOM-free so it can move to a Worker later.
