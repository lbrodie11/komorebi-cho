# 14 — PWA & distribution

## Context (shared by every prompt)
You are working on **Komorebi-chō**, a free, web-first, cozy living-diorama game: a fictional Yanaka-style Tokyo shitamachi block on a walnut plinth. It's rendered in three.js (`WebGLRenderer`, r187+) at low resolution through a palette + Bayer-dither post pass, so it reads as pixel art. Residents follow schedules and a utility AI, notice what the player places, and adapt their routines. **All art and audio are generated by code.** No purchased or commissioned assets, no image or audio files.

Read `CLAUDE.md` and `docs/ARCHITECTURE.md` before touching code. Respect the non-negotiables there:
- code-only art
- the palette is law
- no fail states
- never teleport visible residents
- edits are transactions
- determinism via named RNG streams
- respectful, fictional specificity
- a 60 fps budget

Working method:
- Plan first. List the files you will touch and why.
- Implement in small steps. After each one, run `npm run typecheck` and `npm test`.
- Run the dev server and **look**: capture screenshots (Playwright or the browser) at hours 6, 12, 18 and 22, plus rain. Compare them to the screenshots from before your change.
- New logic in `src/sim`, `src/core` or `src/audio/theory.ts` needs unit tests.
- Don't add a dependency unless it removes more complexity than it adds. Say why.
- Finish with a short report:
  - what changed
  - screenshots
  - known gaps
  - which acceptance criteria you verified, and how

## Goal
Free, installable, offline. The web is the primary home, with itch.io for discovery and an optional desktop wrapper for companion mode.

## Tasks
1. **PWA.**
   - A manifest, plus icons **generated at build time from code** (render the wordmark or plinth to PNG in a Vite plugin using a headless canvas).
   - A service worker that precaches the build so the game works fully offline: cache-first, versioned, with an update prompt.
2. **Hosting.**
   - GitHub Pages with the CI deploy from prompt 01.
   - A custom domain is optional.
   - Security headers where possible (CSP: self, plus fonts if any remain external).
3. **itch.io.** An HTML5 zip build (`npm run build:itch`) with relative paths, a fullscreen button, and a frame size of 1280×720 with responsive fit. Write the page copy in `docs/ITCH.md`.
4. **Desktop companion** (optional, Tauri v2):
   - A borderless, always-on-top, resizable window and a slim strip preset.
   - Start-at-login opt-in, a tray icon with pause, mute and quit, and saves to app data.
   - Test WebGL2 on macOS WKWebView, Windows WebView2 and Linux WebKitGTK. Document any gaps.
   - No Steam, so no overlay concerns.
5. **Versioning.** Semantic versions, a `CHANGELOG.md`, and an in-game "what's new" note (one line, dismissible).

## Acceptance criteria
- A Lighthouse PWA check passes. Airplane-mode reload works after the first visit.
- The itch.io build runs in their iframe without console errors.
- If Tauri is done: the installer is under 15 MB, and companion mode idles under 3% CPU.
